## Array readback recipe

```sh
../sim/run_sim.sh build/vals.elf feat        # feat={-30000, -28889, ..., -29987}   (one line, signed decimal)
```
Host side: `[int(t) for t in line.split("=",1)[1].strip("{}").split(",")]`. The array must be a non-static global the compiler keeps (written or `volatile`). Verified with a 60-element int16 array against a Python oracle (`sim_qa/check_vals.py`). Documented in `sim_qa/README.md`. Larger arrays and `print /x` not tested.
