### Checklist 1: exporter recipe vs C4 section 2 (step by step)

Where the tool differs from `quant_ref.py`, the tool is right. The differences are strictly stricter: `assert` became `BoundError`, with NaN/inf, zero-weight and `x8`-calibration checks added.

- **Step 1 (off/sh):** `choose_norm` is identical to `quant_ref.choose_norm` on the 1500-window calibration set (`off`, `sh` lists equal). Median uses `round` (half-even) on the float median, 0 for odd indices, and P99.9 is taken with `ceil` before the smallest-s search over 0..14. `s` is raised as `GM_IN_SH <= 14` if none fits. Max shift on my data was 9.
- **Step 2 (W1/B1):** `s_w1 = max|W1|/127`, `np.rint` (half-even) for W1 and B1. Identical to `quant_ref.export_quant`.
- **Step 3 (`s_h`):** P99.9 of relu(W1·x8+b1) on the calibration `x8`, computed with the exporter's own `infer_ref.normalize`. Same as the spec.
- **Step 4 (`mshift`):** 0 differences against `quant_ref.mshift` over 20000 random scales plus the edge cases `(2^15-0.4)/2^17`, `2^-17`, `0.5-2^-17`, `0.5-2^-20` and `0.5`. The `M == 2^15` at `SH == 16` case raises (`scale ... >= 0.5 (SH would be < 16)`). At `SH > 16` it halves to `M = 2^14`, `SH-1`.
- **Step 5 (W2/B2/logit scale):** identical arrays to `quant_ref`, `logit_scale 0.0016576893889017356` in both.
- **Step 6 bounds:** weights [-127,127], `|B| < 2^29`, weight-only worst case `< 2^30` for both layers, `2^14 <= M < 2^15`, `16 <= SH <= 31`, `GM_IN_SH <= 14`, offsets in int16. All are in `check_bounds` and raise `BoundError`, which maps to exit 3 (F2 is the one path that escapes). The worst-case bound cannot fire for int8 weights (127·127·60 is under 2^20) and is correct anyway.
- **Hash:** the tool's CRC-32 matches an independent `zlib.crc32` over the concatenated little-endian arrays in file order (`C114C44A`). File order is IN_OFF, IN_SH, W1, B1, M1, SH1, W2, B2 and the render order is the same.
- **`GM_CONF_SHIFT`:** nearest-rank P95 of correct margins, then the smallest `s` with `p95 >> s <= 255`, asserting `<= 24` (`--conf-shift 25` exits 3). On my 600-window set it gave 6 (independent check: P95 = 9762, 9762>>6 = 152, 9762>>5 = 305).
