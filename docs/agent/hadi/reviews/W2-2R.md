## Answers to the checklist

**1. Leakage.** None found.
- norm.json: `export_model.py norm` is run on `ftr` only (`calib.npy` = train features, train.py:325-328). The exporter's `calib`
  (used for the hidden-activation scale s_h) is also train only. Validation features go only to scoring, GM_CONF_SHIFT and
  GM_DEFAULT_REJECT.
- Cache key: sha1 of the complete `int16` window array (pre-split). Features are per-window, so caching before the
  split cannot leak. See L1 for the missing version in the key.
- Grouped split: whole groups move to validation (`val_mask |= group_ids == g`), and the final `groups[:-1]` guarantees a
  non-empty train side. Verified on the synthetic set: subject run train {0,1,2} / val {3}; session run train
  {0,1,3,4,5,6,8,9,10} / val {2,7,11}, disjoint.
- Validation information beyond checkpoint selection: it also sets GM_CONF_SHIFT and GM_DEFAULT_REJECT (via the exporter)
  and the fallback verdict. These are not training signals for the weights, but they are selection uses (M1-M3).

**2. Methodology and concrete fix.** The bias is a maximum-of-candidates bias plus in-sample threshold fitting.
Recommended fix (needs a human decision, since it touches the C4.3 wording):
1. Split into train / val / test (for example 60/20/20, grouped by subject when available, else by session, else
   stratified with a warning). Train fits weights and norm; val selects the checkpoint, GM_CONF_SHIFT and
   GM_DEFAULT_REJECT; **test is scored once on the final header** and is the only source of the reported accuracy,
   confusion matrix and rejection rates. Keep `split.npz` fixed per dataset so the test set stays untouched across runs.
2. The C4.3 fallback ("fixed held-out set, n >= 500") decides which model design is built, so it should **not** use the test
   set (a decision on test makes it no longer untouched). Evaluate it on the fixed validation set (n >= 500) before the
   final test is opened, or on pooled grouped out-of-fold predictions when the dataset is too small for 500 windows. Reword
   C4.3 to say which set. If the data is small, grouped k-fold with pooled predictions gives n >= 500 and an honest
   per-class estimate.
3. Report the test accuracy with a Wilson interval and, if several seeds are run, the mean and spread.
4. GM_CONF_SHIFT / GM_DEFAULT_REJECT: choose on val, then print the rejection rate measured on test (the number that matters
   for users). Also print the fraction of windows with conf below the threshold for class-0 windows and a note when the
   threshold is 0 (L6).

**3. Correctness.**
