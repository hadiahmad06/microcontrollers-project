## G1. Board port (`gesture_port.h`): the only hardware dependency besides `lis3dh_hal.h`
```c
uint8_t  port_tx_room(void);                        /* free bytes in the UART1 TX ring (0..255) */
void     port_tx_write(const uint8_t *p, uint8_t n); /* append n <= port_tx_room() bytes to the TX ring */
uint16_t port_millis(void);                         /* free-running millisecond counter, wraps at 65536 */
bool     port_take_fifo_flag(void);                 /* INT0 (LIS3DH INT1, FIFO watermark) seen since the last call; read-and-clear */
bool     port_take_click_flag(void);                /* INT1 (LIS3DH INT2, click) seen since the last call; read-and-clear */
```
The PIC24 board implements these (later ticket HAL); host tests implement them with fakes.

## G2. Behaviour (beyond API_glue.md)
- `gesture_init`: as API_glue §2; `LIS3DH_ERR_BUS` maps to −2 (API_glue gap 1). Initialises `c2_tx`. Queues the ASCII
  boot line `GM_MODEL_HASH=0x%08lX\n` (8 upper-case hex digits, formatted without printf) through `c2_tx_start_text`
  (C4 D6, C2 §9). Returns 0 on success. Every other function before a successful init does nothing and returns
  false / `GESTURE_UNKNOWN` / 0 (except `gesture_set_reject`, which works before init, C5.2; and `gesture_learn`, which returns
  `GESTURE_LEARN_ERR_NO_WINDOW` before init because 0 would read as a successful learn: ruling 3.7T-1, 2026-11-16).
- `gesture_poll` (non-blocking, bounded): (1) drain if `port_take_fifo_flag()` or >= 50 ms since the last drain
  (`port_millis`, wrap-safe uint16 subtraction): overrun first, then per sample `t = trigger_feed`, `opened =
  capture_push(s, t)`, `if (t && !opened) trigger_release()`; clear the per-window event latch when a window opens.
  (2) click: `if (port_take_click_flag() && lis3dh_read_click() == 1)` set `GESTURE_EVT_DOUBLE_TAP` in `events` and in
  the per-window latch if a window is CAPTURING or READY. (3) TX: if a WINDOW frame is pending and `!c2_tx_busy`, start
  it; else if `stream_on`, a HELLO is pending or due (>= 2000 ms since the last HELLO start) and `!c2_tx_busy`, start a
  HELLO; then pump once: `n = c2_tx_pump(&tx, tmp, port_tx_room()); port_tx_write(tmp, n)` (tmp = 32 B on the stack);
  then `if (c2_tx_take_release(&tx) && capture_release()) trigger_release();`. (4) return true iff the buffer is READY
  and has not been classified yet.
- `gesture_classify`: as API_glue §2. If `stream_on`: mark the WINDOW pending with metadata (`trig_idx` 15,
  `overruns` = capture_stats overruns, `model_hash` = GM_MODEL_HASH, `flags` 1, `class_id`, `conf`, `events` = latch);
  the buffer stays locked until the frame's last byte is queued (C2 §3). Else release at once (`capture_release()`,
  then `trigger_release()` only if it returned true). Returns the id. Calling it twice on the same window returns
  `GESTURE_UNKNOWN` the second time.
- `gesture_learn`: as API_glue §2; clear `x8_valid` after a successful learn (API_glue risk note).
- `gesture_stream_raw(on)`: on a false→true change a HELLO becomes pending. Turning it off while a WINDOW is pending
  or in flight: the frame still completes (frames are atomic, C2 §8), then streaming stops.
- `gesture_events`: read-and-clear (single statement on a uint8, safe because only the main loop writes it: the click
  ISR only sets the port flag).
- **Bring-up build** (`-DGESTURE_BRINGUP_SAMPLES=1`, C2 §10; never in the demo build): `gesture_poll` sends every
  drained sample in SAMPLES chunks of 16 (two 16-row chunk buffers taken from the capture buffer memory, which is unused
  in this build); no trigger, capture or classification; HELLOs as usual; on a FIFO overrun queue the text line
  `OVR <n>\n` (n = total gap events, decimal: FIFO overruns plus drains that lost rows because both chunk buffers
  were full; ruling 3.7T-2, 2026-11-16) between frames so the PC sees the gap. `gesture_poll` returns false.
- C99, fixed-width types, no float, no malloc, no blocking; static RAM of gesture.c (excluding module RAM) <= 160 B on
  avr; doc comment on every function; every board dependency goes through G1 or `lis3dh_hal.h`.
