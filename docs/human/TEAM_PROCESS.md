# Team process

Shared top-level decisions. Edits follow the rules in AGENTS.md §5. Each entry records who
decided it and when.

## Ownership
Everyone owns everything; nothing is split. Any person, or any person's agent, may edit any
code in the repo. Git commit history records who made each change.
- Decided: 2026-11-14 by Hadi. Not contested.
- Note: `docs/archive/proposal.pdf` names a lead for each part. That was the plan as submitted to the
  course. It does not mean ownership.

## Reading
Reading is allowed anywhere in the repo, for humans and agents.
- Decided: 2026-11-14 by Hadi. Not contested.

## AI usage log
`AI_USAGE.md` is one shared file at the repo root. It only needs to tell **agent-written**
code apart from **human-written** code. Which agent, or which person's agent, can be worked
out later from the git history.
